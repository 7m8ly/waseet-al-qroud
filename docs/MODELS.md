## Who produced the test data (disclosure, details in `data/generation/PROVENANCE.md`)
- Claude (Anthropic) wrote the Arabic texts: business activities, loan purposes, the 40 dialogues, the 50 adversarial messages, and drafted the scenario table. A native Iraqi reader still has to review them.
- Applicant names were composed by a script from name lists (synthetic, no real person).
- Wallet transactions were generated by a deterministic script (`data/wallets_make.py`, fixed seed) so that medians and counts match the plan exactly.
- Expected outcomes were planted by hand in `data/cases_spec.py` and cross-checked by an independent calculator (`data/oracle.py`), which must never be imported into the engine.
